# Markdown

## About

Markdown is a lightweight plain-text markup language for writing structured documents.
Created by John Gruber in 2004, it borrows formatting conventions from email and Usenet.
Its source remains readable even before rendering.
It supports headings, emphasis, links, lists, blockquotes, code blocks, and more, and is standardized by CommonMark.
Markdown is commonly converted to HTML.
Its portability and diff-friendly plain-text format have made it a default choice for documentation, READMEs, notes, and [[digital-garden|digital gardens]] like this one.
