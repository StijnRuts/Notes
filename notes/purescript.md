# PureScript

## About

PureScript is a statically typed, purely functional programming language that compiles to JavaScript.
Inspired by [[haskell]], it is strict rather than lazy, and offers type classes, algebraic data types, row polymorphism, and a foreign function interface for interoperating with the JavaScript ecosystem.
Its small generated output and expressive type system make it well suited to frontend and Node.js applications.
