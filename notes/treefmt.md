# treefmt

## About

treefmt is a formatting tool that runs multiple formatters across a project from a single command.
Instead of invoking each formatter separately, projects declare formatters and file patterns in a `treefmt.toml`
or through a flake module such as `treefmt-nix`, and treefmt applies them consistently.
