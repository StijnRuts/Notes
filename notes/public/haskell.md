# Haskell

## About

Haskell is a statically typed, purely [[functional-programming]] language.
It is evaluated lazily by default, and its strong type system supports features such as algebraic data types, type classes, and higher-kinded types.
The Glasgow Haskell Compiler (GHC) is the primary implementation and provides a mature ecosystem for compilers, web services, data processing, and research.
Haskell's emphasis on purity and expressive types has made it influential across the design of many later languages.
