# Functional programming

## About

Functional programming is a paradigm that treats computation as the evaluation of functions.
Programs are built by composing pure functions, which return the same result for the same input and
avoid mutable state and side effects, rather than by issuing step-by-step commands.
This style encourages immutability, higher-order functions, and expressive type systems, making code easier to reason about, test, and parallelize.
Functional ideas are also increasingly common outside dedicated functional languages, through features such as first-class functions, map and fold, and immutable data.
