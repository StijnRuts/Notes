# Zsh

## About

Zsh is an interactive shell and scripting language, and an extended successor to the Bourne shell.
It offers programmable completion, themes, aliases, and a large plugin ecosystem.
This configuration selects Zsh as the shell for the user through [[den]]'s user-shell battery.
