# Home Manager

## About

Home Manager is a [[nix]]-based tool for managing a user's environment declaratively.
From a single configuration it installs packages, writes dotfiles, and configures user-level services and programs,
so the setup can be reproduced, version-controlled, and rolled back.
It can run standalone via `home-manager switch`, or as a [[nixos]] or nix-darwin module, and it uses the same Nixpkgs module system, options, and types as NixOS.
