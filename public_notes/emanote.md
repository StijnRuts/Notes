# Emanote

## About

Emanote is a Haskell-based static site generator and live-preview notebook for turning plain-text [[markdown]] notes into
a structured website, like a personal wiki, [[zettelkasten]], blog, documentation, or [[digital-garden]].
Notes are connected with wikilinks, while YAML frontmatter provides configuration for titles, tags, templates, other metadata.
