# NixOS

## About

NixOS is a Linux distribution built around [[nix]].
The entire system (kernel, packages, services, and configuration) is declared in Nix modules,
and activating a new configuration is an atomic switch that can be rolled back.
This declarative model makes systems reproducible and lets different machines share configuration.
